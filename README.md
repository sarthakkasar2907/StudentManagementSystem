# StudentManagementSystem
Student Management System designed to manage student records through an interactive interface. It Uses Object-Oriented Programming (OOP) principles, Java Collections, and basic File I/O operations.
Features:-
1)Student-->Class Contains 'Name', 'Age', display() method.
2)Interface-->To View, Add and Save Student Record.
3)Input Handling-->Implement Try-Catch Block to prevent crashes from invalid inputs.
Classes:-
Student:Class containing name, age, and a display() method.
GradStudent: Subclass extending Student and an display() method.
SimpleStudentSystem:Class containing the menu loop,ArrayList<Student> collection, and file-writing logic.
Modules Used:-
1)Scanner
2)FileWriter
3)Array List
4)Io Exception
Running the Code Process:-
1)Save the code as StudentManagementSystem.java.
2)Compile the code 
javac StudentManagementSystem.java
