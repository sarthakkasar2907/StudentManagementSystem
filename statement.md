● Problem statement:-
Educational Institutes normally requires lightweight and easy to use tools for managing details of the students in a proper way without too much complex UI.This is a simple software that does data modeling,runtime polymorphism and file based persistence.
● Scope of the project:-

● Target users:-
1)Beginners-Individuals can learn the basis of OOPS in Java.
2)Small Institutes-Users needing rapid and free to use tools for exporting student details to a text file.
● High-level features
The system for dynamic record registration allows user input to be used for creating and storing new student entries in memory, without any limits on the array. There is a menu loop which uses a while loop together with try-catch blocks in order to capture menu choices that are not numeric and to avoid unexpected runtime crashes. The automatic file export function goes through all of the student objects that are currently active and writes the formatted text records directly to a file before the program ends.
